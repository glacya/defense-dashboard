# 개선안 실행계획 — 5W1H와 As-Is / To-Be

작성일: 2026-10-23

## 1. 목적과 작성 기준

[개선안 리스트](개선안리스트.md)와 [선정 매트릭스](선정매트릭스.md)에서 정한 A~E를 실제로 실행할 수 있도록 대상·역할·절차·확인 방법을 정리했다. 첨부 `S4개선안도출5성과유지관리.pdf`의 인쇄 슬라이드 36쪽에 있는 What·Where·When·Who·How·Risk와 As-Is / To-Be 형식을 적용하고, 선정 근거인 Why를 함께 적었다.

수치의 근거는 [분석결과_개선](분석결과_개선.md)과 [심플 분석결과](../심플_분석결과.md)이다. 분석 대상은 첫 측정 당시 19~24세인 표본 3,420명이다. 아래 계획은 **실행 제안**이며 현장에서 이미 시행했거나 효과를 확인한 결과가 아니다.

담당자는 역할로 제안했다. 실제 담당자·착수일·지도 시간·시설·후속 측정일은 실행 전에 정한다. 현재 확인된 상태는 분석자료와 결과이며, 실제 현장의 기존 관리 방식은 확인하지 않았다.

## 2. 실행 순서

| 단계 | 할 일 | 담당 역할(제안) | 완료 기준 |
|---|---|---|---|
| 1. 자료 확인 | 식별자·측정일·회차·결측·BMI 구간·미달 기준 확인 | 분석 담당·검토 담당 | 대상·제외 인원과 적용 기준을 기록 |
| 2. 명단 통합 | A·C·D·E 대상 추출 후 식별자로 합치고 선정 사유 표시 | 분석 담당 | 중복을 제거한 개인별 관리표 작성 |
| 3. 상태 점검 | 원측정값과 측정 당시 상황 확인, 상담·지도 필요 여부 검토 | 지도 담당·관리 담당 | 대상별 담당·점검 결과·다음 점검일 기록 |
| 4. 지도 준비 | B의 운동 지도 내용·인력·시간·시설·참여 기록·평가 방법 결정 | 지도 담당·운영 담당 | 실행 여건이 확인된 시범 계획 마련 |
| 5. 후속 확인 | 같은 대상의 미달 종목 수와 종목별 미달 지속·해소 확인 | 분석 담당·지도 담당 | 평가 가능 인원과 누락 인원을 포함한 결과표 작성 |

A·C·D·E는 선별·점검부터 우선 착수한다. B는 운영 조정 후 시범 적용하며 여건 확인과 계획 준비는 앞 단계와 함께 진행할 수 있다. A·C·D·E 사이의 세부 순위는 실제 측정값·중복 선정 사유·담당 여건을 보고 정한다.

## 3. 개선안별 실행 내용

### A. BMI가 높고 근력·심폐가 미달인 장병 먼저 확인

| 항목 | 실행 내용 |
|---|---|
| What 무엇을 | BMI 높은 그룹 중 실제 근력·심폐 미달 장병을 확인하고 개인별 지도 필요 여부를 점검한다. |
| Why 왜 | 높음 그룹의 근력 미달률 39.70%, 심폐 미달률 49.84%로 관리 필요성이 관찰됐다. |
| Where 어디에 | BMI·체력 분석 결과를 개인별 관리 대상 확인 과정에 적용한다. |
| When 언제 | 자료 확인 후 명단을 작성하고 담당자가 정한 점검일까지 검토한다. 실제 현장 적용 시 최신 측정으로 현재 상태를 다시 확인한다. |
| Who 누가 | 분석 담당은 대상을 추출하고, 지도 담당은 개인 상태와 지도 필요 여부를 검토하며, 관리 담당은 후속 일정을 기록한다. |
| How 어떻게 | 첫 측정 BMI≥25 확인 → 해당 근력·심폐 미달 표시 → 개인 측정값 확인 → C·D·E 명단과 통합 → 현재 상태 검토·조치 기록. |
| Risk 주의사항 | 첫 측정 집단의 미달률을 현재 상태로 간주하지 않는다. BMI만으로 체력·건강 상태나 지도 방법을 결정하지 않는다. 기준·회차 오류 발견 시 재집계한다. |
| 산출물·완료 기준 | 근력·심폐 미달 여부가 표시된 명단과 대상별 점검 결과·후속 일정이 기록되면 점검 단계 완료. |

### B. 심폐·근지구력 미달 장병의 운동 지도 보완

| 항목 | 실행 내용 |
|---|---|
| What 무엇을 | 심폐·근지구력의 기존 지도와 참여 여건을 확인하고 보완 지도 시범안을 만든다. |
| Why 왜 | 심폐 미달률 감소는 1→3차 2.20%p로 작고, 3차 심폐·근지구력 미달률은 각각 24.44%·24.06%다. |
| Where 어디에 | 실제 적용 대상의 체력 지도 시간과 이용 가능한 운동시설에 적용한다. |
| When 언제 | 운영 여건 확인 후 대상·기간·빈도·후속 측정일을 정한다. 자원이 확보되기 전에는 계획 준비를 진행한다. |
| Who 누가 | 지도 담당은 지도안을 검토하고, 운영 담당은 시간·시설을 확인하며, 분석 담당은 성과 확인 방법을 정리한다. |
| How 어떻게 | 현행 지도·참여 상황 확인 → 대상·운영 자원 확정 → 개인 상태를 고려한 지도안 마련 → 시범 적용·참여 기록 → 같은 대상의 후속 결과 확인. |
| Risk 주의사항 | 현재 미달의 원인이 훈련 부족이나 시설 부족이라고 단정하지 않는다. 자원 미확보 시 적용을 보류하고, 지도 중 통증·이상 반응은 활동을 중단하고 담당자에게 확인한다. |
| 산출물·완료 기준 | 대상·기간·담당·시설·참여 기록 방법·평가 방법이 정해지면 시범 준비 완료. 체력 개선 여부는 후속 측정으로 별도 확인. |

### C. 2개 이상 종목 미달 장병을 한 명단으로 관리

| 항목 | 실행 내용 |
|---|---|
| What 무엇을 | 최신 회차에서 2개 이상 체력 종목이 미달한 장병을 관리표에 등록한다. |
| Why 왜 | 3차에도 2개 이상 미달한 장병 826명이 확인됐다. |
| Where 어디에 | 최신 회차의 개인별 체력 관리표와 지도 대상 선정 과정에 적용한다. |
| When 언제 | 회차별 자료 확인 후 명단을 작성하고 새 측정 때 갱신한다. |
| Who 누가 | 분석 담당은 미달 수·종목을 집계하고, 관리 담당은 담당자·점검일을 지정하며, 지도 담당은 지도 필요 내용을 확인한다. |
| How 어떻게 | 4종목 판정 가능 여부 확인 → 2개 이상 미달자 추출 → 미달 종목·개수 표시 → 다른 선정 사유와 통합 → 담당·후속 일정 기록. |
| Risk 주의사항 | 결측을 충족으로 처리하지 않는다. 1개 이상 미달인 ‘취약’과 2개 이상 미달인 이 선정 기준을 혼동하지 않는다. 명단 간 중복을 제거한다. |
| 산출물·완료 기준 | 대상별 미달 종목·담당·점검일이 있는 통합 관리표 작성. |

### D. 미달 종목이 늘어난 장병 상담·재점검

| 항목 | 실행 내용 |
|---|---|
| What 무엇을 | 1차보다 3차 미달 종목 수가 늘어난 장병의 측정값과 상황을 확인한다. |
| Why 왜 | 미달 종목 수가 증가한 장병 529명이 확인됐다. |
| Where 어디에 | 개인별 회차 변화표와 상담·후속 지도 과정에 적용한다. |
| When 언제 | 회차 비교 결과가 나온 후 점검하고 다음 측정에서 상태를 다시 확인한다. |
| Who 누가 | 분석 담당은 동일 장병·회차 연결을 확인하고, 지도·관리 담당은 상태 확인과 상담·조치 내용을 기록한다. |
| How 어떻게 | 1·3차 미달 수 비교 → 새로 미달한 종목과 실제 측정값 확인 → 측정 조건·참여 상황 확인 → 필요한 상담·지도 → 후속 재점검. |
| Risk 주의사항 | 기준선 부근의 작은 변화와 큰 하락을 구분한다. ‘미달 수 증가’를 모든 종목의 악화로 해석하지 않는다. 연결 오류가 있으면 판단을 중지하고 수정한다. |
| 산출물·완료 기준 | 점검 이유·원측정값·상담 또는 조치 결과·후속 일정이 기록된 점검표 작성. |

### E. 같은 종목에서 계속 미달한 장병의 지도 보완

| 항목 | 실행 내용 |
|---|---|
| What 무엇을 | 같은 종목에서 세 회차 모두 미달한 장병을 종목별로 관리한다. |
| Why 왜 | 중복을 제외한 대상은 1,063명(31.08%)이다. 종목별로 근력 254명·근지구력 529명·심폐 377명·유연성 474명이다. |
| Where 어디에 | 종목별 관리 명단과 개인별 지도 계획에 적용한다. |
| When 언제 | 세 회차 확인 후 명단을 작성하고 후속 측정마다 해당 종목의 미달 지속·해소를 확인한다. |
| Who 누가 | 분석 담당은 반복 미달 종목을 확인하고, 지도 담당은 기존 지도·참여 상황을 검토하며, 관리 담당은 후속 기록을 남긴다. |
| How 어떻게 | 동일 종목의 세 회차 판정 확인 → 종목별 명단 작성 → C·D 등 선정 사유와 통합 → 기존 지도·참여·측정 상황 확인 → 개인별 보완 계획 → 후속 확인. |
| Risk 주의사항 | 종목별 대상이 겹치므로 인원을 합산하지 않는다. 매 회차 미달했더라도 종목이 다르면 ‘동일 종목 지속 미달’로 분류하지 않는다. 반복 미달 원인은 확인 후 판단한다. |
| 산출물·완료 기준 | 종목별 명단과 대상별 보완 지도 내용·후속 일정 작성. |

## 4. 대시보드에서의 업무 흐름 — As-Is / To-Be

| 개선안 | As-Is: 현재 확인된 상태 | To-Be: 실행 후 갖출 관리 절차 | 소요 시간 | 판단 근거 |
|---|---|---|---|---|
| A | BMI 그룹별 평균·미달률을 개별 분석 화면에서 확인 가능 | ① BMI별 현황 확인 → ② BMI 높음·근력 또는 심폐 미달 조건으로 명단 조회 → ③ 장병 선택·최신 측정값 확인 → ④ 점검 결과·담당·후속 일정 기록 | 현재 미측정, 화면 연결·기록 기능 구현 후 산정 | 첫 측정 BMI 그룹·실제 미달 여부·최신 측정값 |
| B | 종목별 미달 추이를 분석 화면에서 확인 가능. 현장 지도·시설은 미확인 | ① 종목별 현황에서 심폐·근지구력 추이 확인 → ② 해당 종목 미달자 조회 → ③ 개인별 상태 확인 → ④ 지도 시범 대상·계획·참여 기록 등록 → ⑤ 후속 측정에서 같은 대상의 전후 결과 비교 | 준비·적용 기간은 자원 확인 후 결정 | 종목별 미달률·지도 참여·후속 측정값 |
| C | 위험장병식별 화면에서 조건별 장병 조회·CSV 다운로드 가능 | ① 회차 선택 → ② 2개 이상 미달자 조회 → ③ 장병 선택·미달 종목과 원측정값 확인 → ④ 통합 관리 대상 등록·담당 배정 → ⑤ 점검일에 후속 상태 확인 | 현재 미측정, 실제 점검 부담 확인 후 산정 | 선택 회차·미달 수·종목 조합·관리 기록 |
| D | 개인별 회차 변화 분석 결과 존재 | ① 상태 변화 화면에서 1차 대비 3차 미달 수 증가자 조회 → ② 장병 선택·회차별 값 비교 → ③ 측정 조건·상담 결과 기록 → ④ 지도·재점검 일정 등록 → ⑤ 후속 측정 비교 | 현재 미측정, 기록·화면 연결 구현 후 산정 | 미달 수 증가·실제 측정값·측정 당시 상황 |
| E | 동일종목 지속 미달 화면에서 종목별 대상·개인별 세 회차 기록 조회·CSV 다운로드 가능 | ① 지속 미달 종목 선택 → ② 장병 명단 조회 → ③ 장병 선택·1·2·3차 기록 확인 → ④ 종목별 보완 지도·후속 일정 등록 → ⑤ 다음 측정에서 미달 해소 여부 확인 | 현재 미측정, 지도·측정 일정 확인 후 결정 | 동일 종목 반복 미달·지도 기록·후속 판정 |

To-Be는 제안하는 관리 모습이다. 실제 현장이 이미 같은 방식으로 관리하고 있는지는 착수 전에 확인한다. 시간 단축이나 체력 개선 수치를 임의로 목표로 정하지 않았다.

### 대시보드에서 담당자가 진행할 순서

**자료 갱신·검증 → 전체 현황 확인 → A·C·D·E 조건별 대상 조회 → 장병 선택 → 개인별 측정·변화 확인 → 통합 관리표 기록 → 지도·상담 수행 → 후속 결과 확인**

| 화면·단계(구성안) | 담당자가 화면에서 하는 일 | 남기는 결과 |
|---|---|---|
| 전체 현황 | 측정 회차·대상 인원·종목별 미달률 확인 | 점검할 회차와 종목 결정 |
| 관리 대상 조회 | BMI·실제 미달 여부·미달 수 증가·반복 미달 조건 선택 | 조건과 선정 사유가 표시된 명단 |
| 개인별 상세 | 장병 선택 후 1·2·3차 측정값·미달 종목 확인 | 실제 점검이 필요한 내용 확인 |
| 관리 기록 | 담당자·점검일·상담 결과·지도 계획·다음 점검일 입력 | 개인별 후속 관리 이력 |
| 후속 결과 비교 | 같은 대상의 기준 시점·후속 측정 선택 | 종목별 미달 지속·해소와 미달 수 변화 |

화면 조회 후 지도·상담은 담당자가 현장에서 수행하고, 수행 결과를 다시 기록한다. 대시보드가 운동 지도를 자동으로 수행하거나 지도 효과를 보장하는 것은 아니다.

### 현재 기능과 추가 구현 구분

| 구분 | 현재 확인한 기능 | To-Be를 위해 추가할 기능 |
|---|---|---|
| BMI 분석 | `분석_bmi별.py`의 그룹별 기술통계 | BMI 그룹과 실제 미달 여부를 결합한 장병 명단·개인 상세 연결 |
| 여러 종목 미달 | `위험장병식별.py`의 조건별 장병 조회·CSV 다운로드 | 다른 관리 사유와 명단 통합·담당 배정·개인 상세 연결 |
| 미달 수 증가 | 회차별 미달 수·상태 변화 분석 | 증가자 전용 조회와 개인 상세·관리 기록 화면 연결 |
| 동일 종목 지속 미달 | `동일종목_지속미달분석.py`의 종목별 명단·개인별 세 회차 조회·다운로드 | 지도·상담 기록 저장과 후속 측정 결과 연결 |
| 공통 관리 | 개별 분석 화면·결과 파일 존재 | A·C·D·E 통합 화면, 담당·일정·참여 기록 저장, 동일 대상 전후 비교 |

현재 확인한 기능은 `data/experiments/`의 개별 분석 화면 기준이다. 하나의 대시보드에서 위 흐름 전체가 연결된 상태는 아니다. 위 표의 기록·통합·화면 연결은 **추가 구현 제안**이며 이번에는 실행계획 문서에 반영했다. 구현 전에는 조회 명단을 CSV로 내려받아 별도 관리표에 담당·조치를 기록하는 방식으로 시범 운영할 수 있다.

## 5. 통합 관리표에 기록할 내용

| 구분 | 기록 항목 |
|---|---|
| 식별·측정 | 장병 식별자, 측정일, 회차, 판정 기준 버전 |
| 선정 사유 | A·C·D·E 해당 여부, 미달 종목·개수, 원측정값, 반복·증가 여부 |
| 점검 내용 | 담당자, 점검일, 측정 조건 확인, 상담·지도 검토 결과 |
| 후속 관리 | 조치 내용, B 시범 참여 여부·기록, 다음 점검일, 후속 측정 결과 |

개인별 명단은 실제 적용 시 별도로 작성한다. 이 문서의 인원은 분석 표본의 참고 규모이며 실제 현장 대상 수로 그대로 확정하지 않는다.

## 6. 성과 확인과 유지관리

| 확인할 내용 | 지표·분모 | 확인 시점 | 결과에 따른 조치 |
|---|---|---|---|
| 점검 이행 | 점검 완료 인원 ÷ 중복 제거한 선정 인원 | 정해진 점검일 | 담당·기록·일정 누락 시 보완 |
| 여러 종목 미달 | 후속 2개 이상 미달 인원 ÷ 선정 대상 중 후속 4종목 판정 가능 인원 | 후속 측정 | 기준 시점도 같은 비교 대상에서 계산하고 증가 원인 확인 |
| 종목별 미달 | 해당 종목 미달 인원 ÷ 동일 비교 대상의 해당 종목 평가 가능 인원 | 지도 시범 전·후 측정 | 참여·측정 조건 확인 후 지도 계획 재검토 |
| 지속 미달 해소 | 후속 해당 종목 충족 인원 ÷ 해당 종목 지속 미달 관리 대상 중 후속 평가 가능 인원 | 후속 측정 | 미달 지속 시 지도·참여 상황 재점검 |
| 악화 대상 변화 | 후속 미달 수와 선정 당시 미달 수의 차이 | 후속 측정 | 추가 증가 시 실제 측정값·상황 확인 후 후속 조치 |

목표 수치는 시범 대상의 기준값과 운영 여건을 확인한 뒤 정한다. 후속 측정 누락·탈락 인원을 함께 보고하고 분모가 다른 비율을 그대로 비교하지 않는다. 전후 변화만으로 개선안의 인과효과를 확정하지 않는다.

자료 갱신 시 누락·중복·회차·기준을 확인하고 분포에서 이상해 보이는 값은 원본과 대조한다. 이는 별도 공통 유지관리이며 현재 오류를 발견했다는 뜻은 아니다. G는 예측모형 제출 시 별도 검토할 후보이므로 이번 실행 대상에는 포함하지 않았다.
