# 개인 장병 상세 — 3번 화면

## 실행

```powershell
python -m data.scripts.main analysis
python -m streamlit run dashboard/장병체력_개인상세.py
```

1·2번 분석이 최신이면 `python -m data.scripts.analysis.personal_detail`로 변화 정보만 갱신할 수 있습니다.

## 데이터

- 원본 측정·가상 장병 명단·가상 부상 원본은 유지하고 읽기만 합니다.
- 2번의 management_targets.csv에서 회차·등급·미달·관리 사유를 재사용합니다.
- 추가 산출물: `data/processed/analysis/personal_detail/personal_changes.csv` 및 metadata.json.
- CSV 한 행은 장병의 측정 1건이며 MESURE_ID+SOLDIER_ID로 원본에 연결합니다.
- 주요 컬럼: MESURE_ID, SOLDIER_ID, ROUND, FIRST_MESURE_ID, 종목별 *_CHANGE, *_GRADE_CHANGE, IMPROVED_EVENTS.
- 측정값 변화는 현재−1차이며, 등급은 1등급이 가장 높고 0은 3등급 미만입니다. 빈칸·연령 범위 밖은 판정 불가입니다.
- 미달 해소는 1차 미달→현재 1·2·3등급인 종목으로, 신규 미달은 반대 전환입니다. 두 시점 모두 판정 가능해야 합니다.

## 화면

1. 이름·장병번호 검색과 장병 선택
2. 측정 회차 선택 (기본 최신)
3. 기본·신체 정보: 신상, 측정 당시 나이, 키·체중·BMI·구간·체지방률
4. 체력측정·등급: 종목별 측정값·단위·기준·등급·판정·관리 사유
5. 회차별 변화: 1차 대비 값·등급 변화, 미달 개수·종목 변화, 최근 세 회차 지속 미달, 전체 회차 그래프
6. 부상 이력: 부상 대분류·부위·심각도·예방 가능 여부

부상 원본에는 발생일·회복 상태·운동 제한이 없어 생성하지 않습니다.
이력 전체를 표시하며 특정 측정 당시의 부상으로 해석하지 않습니다.
파일이 없으면 자료 없음, 파일은 있지만 해당 장병 기록이 없으면 보유 기록 없음으로 구분합니다.
전체 회차 그래프는 선택 회차 이후의 보유 측정도 보여주며 선택 회차를 점선으로 표시합니다.
신상·부상은 합성 자료이며 실제 개인 건강 진단이 아닙니다.
