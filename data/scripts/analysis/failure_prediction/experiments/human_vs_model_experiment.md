# 실험: 사람 vs 미달 예측 모델

미달 예측 모델(`failure_prediction/`)이 사람보다 3차 체력검정 미달을 얼마나 더 정확하게, 얼마나 더 빨리 판정하는지 확인합니다.

## 질문

1. 같은 정보(1·2차 측정값)를 보고 3차 미달 여부를 판정할 때, 모델의 Precision은 사람보다 높은가?
2. 100문항을 판정하는 데 걸리는 시간은 얼마나 차이 나는가?

## 문제 설정

모델은 장병의 1·2차 측정을 보고 3차 측정의 미달 여부를 예측합니다. 사람도 똑같이 풀어야 공정하므로, 문항마다 한 장병의 1·2차 측정값을 보여 주고 3차 결과를 묻습니다. 3차 측정값 자체를 보여 주면 등급컷만 대조하면 되는 문제가 되어 모델과 비교할 수 없습니다.

| 항목 | 내용 |
|---|---|
| 문항 | 측정 10,746건(`data/processed/KS_NFA_PROCESSED.csv`)을 시드(기본 20261103)로 무작위로 섞은 순서대로 그 측정의 장병을 골라, 같은 장병은 한 번만 넣어 100명 |
| 보여 주는 값 | 1차·2차 측정의 근력·근지구력·심폐·유연성·BMI. 종목별 1·2·3등급컷(`fitness_standards.grade_cut`)은 화면 옆에 계속 보입니다. |
| 정답 | 3차 측정에서 3등급 하한 미만 종목이 2개 이상이면 미달, 아니면 합격(모델 학습 규칙과 같음) |
| 사람의 답 | 문항마다 합격/미달 중 하나. 답하지 않은 문항은 어느 쪽으로도 세지 않습니다. |
| 모델의 답 | 미달 확률 0.5 이상이면 미달. 입력은 2차 측정값 4개, 1→2차 변화량 4개, 2차 BMI의 정상범위 중앙(21.75) 이탈 제곱. 0.5는 모델 검증(`build_failure_probability_model.py`)에서 정밀도를 계산한 기준과 같습니다. |

## 기준 지표

**Precision**(미달 정밀도) = 미달이라고 답한 문항 중 실제 미달 문항 수 ÷ 미달이라고 답한 문항 수.

미달은 전체의 약 4분의 1뿐이라, 정답률은 모두 합격으로 찍기만 해도 높게 나옵니다. 그래서 정답률 대신 Precision을 기준으로 삼습니다. 이 기준은 "미달이라고 짚은 장병이 실제로 미달인가", 곧 후속조치 대상을 고를 때의 정확도를 뜻합니다. 재현율(실제 미달 중 미달이라고 답한 비율)과 전체 정답률은 참고로 함께 보여 줍니다. 모두 미달로 답하면 Precision은 문항의 실제 미달 비율과 같으므로 이를 기준선으로 봅니다. 미달이라고 답한 문항이 하나도 없으면 Precision은 계산하지 않습니다.

## 측정 방법

- **사람 시간**: 페이지에서 **시작**을 누른 때부터 **최종 제출**을 누른 때까지. 빨리 푸는 실험이 아니므로 푸는 동안에는 타이머를 보여 주지 않고, 진행도(답한 문항 수)만 보여 줍니다. 규칙과 등급컷은 시작 전에 읽을 수 있습니다.
- **모델 시간**: 제출하는 순간 같은 브라우저에서 화면에 보인 1·2차 값으로 100문항을 반복 계산해(최소 200ms 또는 50회) 1회 평균을 잽니다. 첫 실행은 재지 않습니다.
- 제출하기 전에는 결과·정답·모델의 답을 보여 주지 않습니다.

## 절차

1. `python data/scripts/analysis/failure_prediction/experiments/build_human_vs_model_quiz.py`로 문항 페이지를 만듭니다(`data/intermediate/human_vs_model/human_vs_model_quiz.html`, Git 제외). 실험 참가자가 볼 수 있도록, 스크립트는 문항의 정답 분포나 문항에서의 모델 성적을 출력하지 않습니다.
2. 참가자는 페이지에서 규칙과 등급컷을 읽고 **시작**을 누른 뒤 100문항에 답하고 **최종 제출**을 누릅니다.
3. 결과 화면의 Precision·재현율·정답률·시간을 기록합니다. 참가자가 여럿이면 같은 문항(같은 시드)으로 진행합니다. 문항의 정답을 미리 알게 된 사람이 있으면 다른 시드로 문항을 다시 뽑습니다.

## 미리 알아 둘 한계

- 모델은 이 문항의 장병을 포함한 전체 장병 3,582명으로 학습했습니다. 그래서 문항에서의 모델 결과는 처음 보는 데이터에서보다 좋게 나올 수 있습니다. 전체 장병 기준 모델 Precision은 76.1%, 재현율은 56.0%입니다.
- 정답은 페이지 소스에 섞인 형태로 들어 있습니다. 소스를 열지 않는다는 전제로 진행합니다.
- 사람 시간에는 화면을 읽고 누르는 시간이 포함되고, 모델 시간은 계산만 잽니다. 시간 비교는 "같은 판정 100건을 내는 데 걸리는 시간"으로 해석합니다.
- 미달이라고 답한 문항 수가 적으면 Precision이 몇 문항 차이로 크게 바뀝니다. 참가자가 여럿이면 평균과 범위를 함께 보고, 미달이라고 답한 문항 수도 함께 기록합니다.
