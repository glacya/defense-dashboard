# 체력 집중관리 대상자 — 2번 화면

## 실행

프로젝트 루트에서 실행합니다.

```powershell
python -m data.scripts.main analysis
python -m streamlit run dashboard/장병체력_집중관리대상자.py
```

2번 분석만 갱신할 때는 `python -m data.scripts.analysis.management_targets`를 사용합니다.
1번과 관리 인원을 맞추려면 전체 analysis 명령으로 둘 다 갱신합니다.

## 선정 조건

| 컬럼 | 선정 조건 |
|---|---|
| HIGH_BMI_FAIL | BMI≥25이며 근력 또는 심폐가 실제 미달 |
| MULTIPLE_FAIL | 선택 회차 네 종목 모두 판정 가능하고 미달 개수가 2개 이상 |
| WORSENED | 1차와 선택 회차의 미달 개수가 확정돼 있고 선택 회차가 더 많음 |
| PERSISTENT_FAIL | 선택 회차까지 최근 세 회차의 동일 종목이 모두 판정 가능하고 미달 |
| MANAGED | 위 조건 중 하나 이상 해당 |

원본 모든 측정에 개인별 날짜순 회차를 부여하며 같은 날짜는 원본 입력 순서입니다.
1차에는 악화·3회 지속 미달, 2차에는 3회 지속 미달을 판정하지 않습니다.
미래 자료를 사용하지 않습니다. 현재 3회 측정 자료에서는 악화가 1→3차,
지속 미달이 1·2·3차 기준입니다. 소속 필터·소속 비교는 제공하지 않습니다.

측정 당시 남성 19~24세 기준을 적용합니다. 범위 밖 연령·누락은 판정 불가입니다.
선정 False는 조건이 확인되지 않았다는 뜻이며 양호·통과를 보장하지 않습니다.
BMI만으로 상태나 지도 방법을 결정하지 않으며 부상 위험 예측과 구분합니다.

## 산출물

위치: `data/processed/analysis/management_targets/`

| 파일 | 한 행의 기준 | 내용 |
|---|---|---|
| management_targets.csv | 장병·회차(측정) | 식별자, BMI 구간, 판정 가능 수·미달 수, 1차 비교 식별자·미달 수 변화, 미달·신규·지속 미달 종목, 네 선정 조건, 통합 여부·사유, 종목별 등급 |
| target_summary.csv | 회차·선정 사유 | 측정 인원·대상 인원. MANAGED는 중복 제거한 인원 |
| metadata.json | 분석 실행 | 생성일·입력 자료·판정 기준·표본 및 해석 안내 |

CSV에는 비대상 측정도 포함해 필터와 집계 기준을 보존합니다. 화면 명단에는 MANAGED=True만 표시합니다.
원본 측정값은 다시 저장하지 않고 `MESURE_ID`+`SOLDIER_ID`로 기존 측정 자료에 연결합니다.
신상은 `SOLDIER_ID`로 기존 합성 장병 명단에 연결합니다. 원본·실험 파일은 수정하지 않습니다.
같은 장병이라도 여러 회차가 포함돼 있으므로 전체 파일 행수를 대상 장병 수로 사용하지 않습니다.

## 화면

- 측정 회차, BMI 구간, 선정 사유, 미달 개수·종목, 이름·식별자 필터
- 회차 측정 인원, 중복 제거 통합 대상 인원·비율, 필터 결과 인원
- 사유별 인원 그래프: 필터 적용 전 회차 전체 대상 기준. 사유 간 중복되므로 합산 금지
- 명단·선정 사유·CSV 다운로드
- 선택 장병의 1차·현재 측정값·기준값·등급, 해당 시점까지 회차별 변화

관리 비율은 선택 회차 측정 인원이 분모이며 판정 불완전 인원도 포함합니다.
사유 미선택은 모든 사유, 복수 선택은 하나 이상 해당(OR)입니다.
