# 분석결과 정리

| 분석주제 | 개선으로 연결할 내용 | 반영구분 | 개선안 포함여부 | 반영기준 |
|---|---|---|---|---|
| 연령별 체력·신체 현황 | 연령별 수준을 참고하되 평균만으로 지도 대상을 정하지 않음 | 기초자료 활용 | 미포함 | 연령별 기본 현황을 보여주는 자료로, 이 결과만으로 구체적인 관리 대상이나 방법을 정하기 어려움 |
| BMI 그룹별 체력·신체 현황 | BMI별 차이를 개인별 체력 점검의 참고정보로 활용 | A의 보조 근거 | 포함(보조 근거·A) | BMI별 관측 차이를 보여주므로 A의 배경자료로 활용하되, 별도 개선안은 만들지 않음 |
| 연령별 체력 평균 차이 | 연령만으로 별도 지도 집단을 나눌 근거가 약함 | 별도 개선안 제외 | 미포함 | 대부분 종목에서 유의한 차이가 없고 유연성 차이도 작아 연령별 별도 관리의 근거가 약함 |
| BMI 그룹별 체력 평균 차이 | 차이가 큰 근력·심폐 항목을 실제 미달자 점검에 연결 | A에 통합 | 포함(A에 통합) | BMI 그룹 간 평균 차이가 확인되고 특히 상대악력·심폐 차이가 커 실제 미달자 점검의 근거가 됨 |
| 연령과 체력 미달의 관련성 | 연령 구분보다 개인별 미달 상태에 기반한 관리 | 별도 개선안 제외 | 미포함 | 유연성 관련성의 크기가 작고 다른 종목의 관련성도 뚜렷하지 않아 연령만으로 대상을 나누기 어려움 |
| BMI 그룹과 체력 미달의 관련성 | BMI 높은 그룹의 실제 근력·심폐 미달자 우선 점검 | A: BMI 높은 그룹 미달자 점검 | 포함(A) | BMI 높은 그룹의 근력·심폐 미달률이 높게 관찰돼 실제 미달자를 우선 확인할 근거가 됨 |
| 회차별 체력 측정값의 상관 | 이전 기록을 후속 점검의 참고자료로 활용 | 추적 점검 보조자료 | 미포함 | 회차 간 순위가 유지되는 경향만으로는 누구에게 어떤 조치가 필요한지 정하기 어려워 참고자료로 활용 |
| 종목별 미달 규모 변화 | 감소 폭이 작은 심폐와 미달이 많이 남는 근지구력의 지도 보완 | B: 심폐·근지구력 지도 보완 | 포함(B) | 심폐의 미달률 감소가 작고 근지구력도 미달이 많이 남아 종목별 지도 보완을 검토할 필요가 있음 |
| 여러 종목 미달 장병 규모 | 여러 종목 미달 장병의 통합 관리 | C: 여러 종목 미달자 관리 | 포함(C) | 최신 회차에도 2개 이상 미달한 826명이 확인돼 관리 대상을 구체적으로 선별할 수 있음 |
| 개인별 체력 상태 변화 | 미달 수 증가 장병의 상태 확인과 후속 조치 | D: 악화 장병 후속 점검 | 포함(D) | 미달 종목 수가 증가한 529명을 확인할 수 있어 상태 점검과 후속 조치 대상으로 연결 가능 |
| 동일 종목 지속 미달 | 반복 미달 종목에 대한 집중 관리 | E: 동일 종목 지속 미달 관리 | 포함(E) | 같은 종목에서 세 회차 모두 미달한 대상이 확인돼 반복 미달 종목별 관리로 연결 가능 |
| 심폐 평균과 기준값 44.8 비교 | 전체 평균과 개인별 미달 상태를 구분 | B의 보조자료, 별도 과제 제외 | 미포함(별도 개선안) | 현재 평균 44.56은 비교 기준 44.8보다 낮지만, 평균 비교만으로 개인별 지도 대상을 정할 수 없어 B의 참고자료로만 활용. 개인별 미달 기준은 42.0 |
| BMI 낮음·높음 상대악력 평균 차이 | BMI별 상대악력 차이를 점검에 활용하되 중복 과제 방지 | A의 보조 근거 | 포함(보조 근거·A) | 낮음·높음 그룹의 상대악력 차이를 확인한 보조 근거이며 4·6번과 중복돼 A로 통합 |
| 체력·신체 6개 항목 전체 분포 | 항목별 분포와 자료 누락 여부를 확인하는 기초자료로 활용 | 자료 현황 확인 | 미포함 | 결측이 없다는 결과만으로 입력 오류가 없다고 판단할 수 없으며, 현재 결과에서 별도 개선이 필요한 문제가 확인된 것은 아님 |
| BMI와 체력항목의 비선형성 탐색 | 모든 체력 항목을 BMI와 같은 형태의 관계로 해석하지 않음 | 해석 보완 / G는 조건부 검증 후보 | 본 개선안 미포함(후보 G) | 곡선 경향만으로 예측 성능 개선을 확정할 수 없으므로 예측모형 제출 시 검증할 후보로만 관리 |
| BMI와 Z-score 체력종합점수 | 종합점수와 개별 종목을 함께 확인 | 탐색 참고자료 | 미포함 | 탐색용 종합점수이며 공식 통과 기준이나 개인별 지도 기준으로 검증되지 않아 참고자료로 활용 |
