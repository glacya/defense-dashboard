# 모듈 작성 요령

`.py` 파일을 새로 만들거나 고칠 때 지켜야 할 규칙입니다. 목표는 다음 두 가지입니다.

1. 누가 열어도 같은 위치에서 같은 내용을 찾을 수 있게 합니다.
2. 다른 파일에서 import했을 때 예상하지 못한 동작이 일어나지 않게 합니다.

## 1. 코드의 순서

모든 모듈은 아래 순서를 따릅니다.

```python
"""① 모듈 설명 (docstring)

CSV 원본 파일을 읽어 표준 형식으로 가공합니다.
"""

# ② import
import logging
from pathlib import Path

import pandas as pd

from config import CSV_DATA_DIR, CSV_FINAL_DIR

# ③ 전역 값 (상수, 로거)
logger = logging.getLogger(__name__)

ENCODING = "utf-8"
_REQUIRED_COLUMNS = ["부대", "날짜", "식단"]


# ④ 함수 / 클래스
def load_csv(path: Path) -> pd.DataFrame:
    """CSV 파일을 읽어 DataFrame으로 반환합니다."""
    return pd.read_csv(path, encoding=ENCODING)


def normalize(df: pd.DataFrame) -> pd.DataFrame:
    """필수 컬럼만 남기고 결측 행을 제거합니다."""
    return df[_REQUIRED_COLUMNS].dropna()


# ⑤ 메인 루틴
def main() -> None:
    for path in CSV_DATA_DIR.glob("*.csv"):
        df = normalize(load_csv(path))
        df.to_csv(CSV_FINAL_DIR / path.name, index=False, encoding=ENCODING)
        logger.info("처리 완료: %s", path.name)


# ⑥ 직접 실행할 때만 동작
if __name__ == "__main__":
    main()
```

### ① 모듈 설명
- 반드시 **파일 맨 첫 줄**에 둡니다. Python은 첫 번째 문장으로 온 문자열만 docstring으로 인식합니다. import 아래에 적은 문자열은 아무 역할도 하지 않는 그냥 문자열입니다.
- 이 파일이 **무엇을 하는지**, **왜 존재하는지**를 1~3줄로 적습니다.

### ② import
- 모든 import는 **파일 맨 위에 모아서** 씁니다. 함수 정의 사이사이에 import를 두지 않습니다.
- 아래 세 그룹으로 나누고, 그룹 사이는 한 줄 띄웁니다.
  1. 표준 라이브러리 (`os`, `logging`, `pathlib` 등)
  2. 외부 패키지 (`pandas`, `streamlit` 등)
  3. 프로젝트 내부 모듈 (`config`, `dashboard.xxx` 등)
- 프로젝트 내부 모듈은 **루트 기준 절대 경로**로 import합니다.
  ```python
  from config import CSV_DATA_DIR             # O
  from dashboard.py.loader import load_css    # O
  from .loader import load_css                # X (상대 import)
  ```
- `sys.path.insert(...)`로 경로를 조작하지 않습니다. `setup.ps1`이 프로젝트를 설치(`pip install -e .`)해 두었으므로 어디서든 위 import가 동작합니다.
- `from xxx import *`는 쓰지 않습니다. 어떤 이름이 어디서 왔는지 알 수 없게 됩니다.
- 파일 경로는 문자열로 직접 쓰지 말고 `config.py`의 값을 사용합니다.

> **순환 import 주의**: A 파일이 B를 import하고 B도 A를 import하면 `ImportError: cannot import name ... (most likely due to a circular import)`가 납니다. 두 파일이 함께 쓰는 코드를 별도 모듈로 분리해서 해결하세요.

### ③ 전역 값
- 바꾸지 않을 값(상수)은 `UPPER_SNAKE_CASE`로 씁니다.
- 이 파일 안에서만 쓰는 값은 이름 앞에 `_`를 붙입니다. 예: `_REQUIRED_COLUMNS`
- 전역 변수의 값을 함수 안에서 바꾸지 않습니다(`global` 사용 금지). 필요한 값은 인자로 받고 결과는 반환합니다.

### ④ 함수 / 클래스
- 함수 하나에는 일 하나만 맡깁니다. 이름은 `snake_case` 동사로 시작합니다. 예: `load_csv`, `normalize_columns`
- 인자와 반환 값에 타입 힌트를 붙입니다.
- 들여쓰기는 **공백 4칸**입니다. VS Code에서 저장할 때 자동 정렬되도록 설정해 두면 편합니다.

### ⑤ 메인 루틴 / ⑥ `if __name__ == "__main__":`
- 실제로 일을 실행하는 코드(파일 읽기·쓰기, DB 접속, API 호출, `print`)는 `main()` 함수 안에 넣습니다.
- `main()`은 `if __name__ == "__main__":` 아래에서만 호출합니다.

**이유**: Python은 파일을 import하는 순간 그 파일의 맨 위부터 끝까지 실행합니다. 실행 코드가 함수 밖에 있으면, 다른 파일이나 테스트에서 함수 하나만 가져다 쓰려고 import해도 그 코드가 전부 실행됩니다. `if __name__ == "__main__":` 아래의 코드는 `python 파일명.py`로 **직접 실행했을 때만** 동작합니다.

> **예외 — Streamlit 앱 파일** (`dashboard/app.py` 등): `streamlit run`은 파일 전체를 위에서부터 실행하는 방식이라, 화면을 그리는 코드를 최상위에 두어도 됩니다. 대신 앱 파일에는 화면 구성만 두세요. 데이터 처리 로직은 별도 모듈로 분리하면 그 모듈만 따로 import해서 테스트할 수 있습니다.

## 2. 주석 작성

### docstring (함수·클래스 설명)
public 함수(이름이 `_`로 시작하지 않는 함수)에는 docstring을 씁니다. 한 줄로 충분하면 한 줄로 끝냅니다. 인자나 예외 설명이 필요하면 아래 형식을 따릅니다.

```python
def load_csv(path: Path, encoding: str = "utf-8") -> pd.DataFrame:
    """CSV 파일을 읽어 DataFrame으로 반환합니다.

    Args:
        path: 읽을 CSV 파일 경로
        encoding: 파일 인코딩. 공공데이터 원본은 "cp949"인 경우가 많음

    Returns:
        원본 컬럼을 그대로 유지한 DataFrame

    Raises:
        FileNotFoundError: path에 파일이 없을 때
    """
```

### 일반 주석 (`#`)
- 코드가 **무엇을** 하는지가 아니라 **왜** 그렇게 하는지를 적습니다. 무엇을 하는지는 코드를 읽으면 알 수 있습니다.
  ```python
  # X: 코드를 그대로 다시 읽은 주석
  df = df.dropna()  # 결측치 제거

  # O: 코드만 봐서는 알 수 없는 이유
  # 2023년 이전 데이터는 '체중' 컬럼이 비어 있어 분석 대상에서 제외
  df = df.dropna(subset=["체중"])
  ```
- 데이터 출처, 단위, 예외 처리 이유처럼 **코드 밖의 사정**은 꼭 남깁니다.
- 할 일은 `# TODO(이름): 내용` 형식으로 적습니다. 나중에 검색하기 쉽습니다.
- 지운 코드를 주석 처리해서 남겨두지 않습니다. 이전 코드는 git 기록에 남아 있습니다.
- 구역 구분선(`# ====`)은 파일이 길어 구역이 여러 개일 때만 쓰고, 구분선 바로 아래에 그 구역의 코드를 둡니다.

## 3. 제출 전 체크리스트

- [ ] 모듈 docstring이 파일 첫 줄에 있다
- [ ] import가 파일 맨 위에 세 그룹으로 정리되어 있다
- [ ] `sys.path` 조작이나 하드코딩된 경로가 없다
- [ ] 실행 코드가 `main()` 안에 있고, `if __name__ == "__main__":`로 호출된다 (Streamlit 앱 파일 제외)
- [ ] public 함수에 docstring과 타입 힌트가 있다
- [ ] 새로 만든 함수에 대한 테스트가 `tests/`에 있다 ([테스트 작성법](테스트-작성법.md) 참고)
