# 데이터 관리 요령

이 프로젝트에서 데이터 파일을 다룰 때 지켜야 할 규칙입니다.

## 1. 원본 데이터와 파생 데이터는 Git에 올리지 않습니다

| 종류 | 설명 | Git 업로드 |
|---|---|---|
| 원본 데이터 | 데이터 제공처에서 받은 파일 | **금지** |
| 파생 데이터 | 원본을 가공해서 만든 파일 (전처리 스크립트의 결과물 등) | **금지** |
| 가상 데이터 | 직접 생성한 가상의 데이터 | 허용 |

**이유**
- 공유 저장소의 용량을 줄입니다. 원본 데이터만 합쳐도 약 600MB입니다.
- 현재 사용하는 데이터셋은 CC-BY 라이선스로 공개된 데이터입니다. 그래도 원본 데이터를 공개 저장소에 그대로 올리지 않는 것이 좋은 관습이므로 이 규칙을 따릅니다.

**커밋 전 확인**
현재 `.gitignore`는 `data/csv_file/csv_data/KS_NFA_*.csv`만 자동으로 제외합니다. 다른 이름으로 데이터 파일을 만들었다면, 커밋하기 전에 `git status`로 그 파일이 목록에 올라와 있지 않은지 확인하세요.

## 2. 원본 데이터

### 출처
문화 빅데이터 플랫폼 — 체력측정 및 운동처방 종합 데이터
<https://www.bigdata-culture.kr/bigdata/user/data_market/detail.do?id=b3924850-aa65-11ec-8ee4-95f65f846b27>

### 파일 구성
- 파일 이름 형식: `KS_NFA_FTNESS_MESURE_MVN_PRSCRPTN_GNRLZ_INFO_YYYYMM.csv`
- 범위: **202201 ~ 202607, 202205 제외, 총 54개**
- 컬럼 정의: `data/csv_file/csv_define/KS_NFA_COLUMN_DEFINITION.csv`. 이 파일은 Git에서 관리합니다.

### 위치
54개 파일을 **모두 `data/csv_file/csv_data/` 폴더에** 둡니다. 하위 폴더를 만들지 말고 바로 아래에 둡니다.

파일 이름은 받은 그대로 둡니다. 전처리 스크립트가 `KS_NFA_FTNESS*.csv`라는 이름 패턴으로 원본 파일을 찾기 때문에, 이름을 바꾸면 그 파일을 읽지 못합니다.

## 3. 전처리 스크립트 작성 규칙

- 모든 전처리 스크립트는 **`data/csv_file/csv_data/` 폴더에 원본 데이터(또는 파생 데이터)가 있다**고 전제하고 작성합니다.
- 폴더 경로는 문자열로 직접 쓰지 말고 `config.py`의 `CSV_DATA_DIR`을 사용합니다.
  ```python
  from config import CSV_DATA_DIR

  INPUT_PATH = CSV_DATA_DIR / "KS_NFA_TOTAL.csv"
  ```
- 파생 데이터 파일의 이름은 `KS_NFA_FTNESS`로 시작하면 안 됩니다. 원본 파일로 잘못 인식되어 다음 전처리 때 원본과 함께 읽힙니다.
- 스크립트가 다른 스크립트의 결과물을 입력으로 쓴다면, 모듈 docstring에 어떤 스크립트를 먼저 실행해야 하는지 적습니다.
- 그 밖의 코드 작성 규칙은 [모듈 작성 요령](모듈-작성-요령.md)을 따릅니다.

### 현재 전처리 순서

| 순서 | 스크립트 | 입력 | 출력 (`csv_data/`) |
|---|---|---|---|
| 1 | `data/data_merger.py` | 원본 54개 | `KS_NFA_TOTAL.csv` |
| 2 | `data/collect_high_freq_soldiers.py` | `KS_NFA_TOTAL.csv` | `KS_NFA_THREE_MEASURES.csv` |

```powershell
conda run --no-capture-output -n kdt-project-1 python data/data_merger.py
conda run --no-capture-output -n kdt-project-1 python data/collect_high_freq_soldiers.py
```

> `--no-capture-output` 옵션을 빼면 Windows에서 한글을 출력하다가 `UnicodeEncodeError`가 날 수 있습니다. 이때 스크립트 작업 자체는 정상적으로 끝나지만, 종료 코드는 1로 나옵니다.
