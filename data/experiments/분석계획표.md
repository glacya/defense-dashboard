작성 기준: 현재 `data/experiments/`의 분석 코드와 사용한 데이터·판정 기준을 정리한 계획표입니다. 이미 수행한 분석을 포함하며, 분석 전에 등록한 계획서는 아닙니다.

## 1. 분석 목적과 대상

장병의 체력 측정 현황을 파악하고, 연령·BMI에 따른 체력 평균과 미달 여부의 차이를 확인합니다. 또한 1·2차 체력 상태에 따른 실제 3차 통과율을 집계하고 로지스틱 회귀의 개인별 예측확률과 구분합니다.

| 구분 | 내용 |
|---|---|
| 측정 데이터 | `data/processed/KS_NFA_PROCESSED.csv` |
| 컬럼 정의서 | `data/definitions/KS_NFA_FINAL_DEFINITION.csv` |
| 3등급기준표 | `data/scripts/fitness_standards.py`의 `grade3_standards()` (이전 `data/definitions/grade3_male_19_24.csv`) |
| 현재 데이터 규모 | 10,746개 측정 기록, 장병 3,582명, 1인당 3회 측정. 2026-10-26 현재 CSV 기준이며 데이터 갱신 시 재집계 |
| 원자료 성격 | 국민체력100 남성 19~24세 자료를 분석에서 장병 표본으로 사용. 실제 특정 부대 전체 모집단이라는 의미는 아님 |
| 전처리 대상 | 전처리 필터와 측정 기록 선정 조건을 통과한 자료. 원본 전체 19~24세 남성을 모두 분석한 결과는 아님 |
| 첫 측정 분석 | 장병별 날짜순 첫 측정 1건 사용. 동일 날짜이면 원본 행 순서 적용 |
| 반복 측정 분석 | 동일 장병의 1·2·3차 기록을 연결하여 비교 |
| 연령 범위 | 첫 측정 분석은 첫 측정 당시 19~24세. 회차별 분석은 코드의 연령 필터에 따라 선정 |

| `회차` / `round` | 장병별 날짜순 1·2·3차, 코드별 명칭 다름 | 회차별 비교·측정값 연결 |

### BMI 그룹

대한비만학회 「비만 진료지침 2022」의 성인 분류를 통합한 분석용 3그룹을 사용합니다.

|---|---|---|
| 낮음 | BMI < 18.5 | 저체중 |

첫 측정의 유효 BMI(0 초과)에 고정 경계를 적용합니다. 보통은 정상체중만을 뜻하지 않습니다. 현재 인원은 낮음 75명·보통 2,073명·높음 1,272명입니다.

## 5. 통계 검정과 계산 기준

| 구분 | 현재 코드의 적용 규칙 |
|---|---|
| ANOVA 귀무가설 | 연령 또는 BMI 그룹의 해당 체력 종목 평균이 모두 같다 |
| ANOVA 방법 선택 | 종목별 중앙값 기준 Levene p ≥ 0.05이면 일반 ANOVA, p < 0.05이면 Welch. 이는 현재 코드의 선택 규칙이며 등분산의 증명을 뜻하지 않음 |
| ANOVA 판단 | 선택된 검정의 원 p값 < 0.05. 종목 사이 Holm 보정은 현재 적용하지 않음 |
| 사후검정 | 전체 검정이 유의한 경우 일반 ANOVA → Tukey HSD(불균형 인원은 Tukey–Kramer), Welch → Games–Howell |
| 사후검정 판단 | 해당 종목 내 모든 쌍을 고려한 보정 p값 < 0.05. 연령 15쌍, BMI 3쌍 |
| 효과크기 | η²는 일반 ANOVA의 집단 간 제곱합/전체 제곱합. Welch의 검정통계량에서 계산한 효과크기는 아님 |
| 카이제곱 귀무가설 | 연령 또는 BMI 그룹과 해당 종목의 미달 여부가 독립이다 |
| 카이제곱 판단 | 종목별 원 p값과 Holm 보정 p값을 표시하고, 보정 p값 < 0.05로 판단 |
| 기대빈도 점검 | 기대빈도 1 미만 셀이 있거나, 5 미만 셀이 20%를 넘으면 점근 근사 해석에 주의 표시 |
| 카이제곱 효과크기 | Cramér’s V. 평균 차이에 대한 η²와 구분 |
| 상관분석 | Pearson은 선형 관계, Spearman은 순위의 단조 관계. 현재 원 p값을 보고하며 다중검정 보정 없음 |
| 관측 통과율 | 그룹 3차 통과 인원 ÷ 그룹 3차 판정 가능 인원 |
| 동일종목 지속 미달률 | 하나 이상의 동일 종목에서 세 회차 모두 미달한 고유 장병 수 ÷ 세 회차 네 종목 모두 판정 가능한 고유 장병 수 × 100 |
| 인원 변동률 | (비교 회차 미달 인원−기준 회차 미달 인원) ÷ 기준 회차 미달 인원 × 100 |
| 0명 처리 | 통과자 0명·평가자 양수이면 0%. 평가자 0명이면 통과율 공란. 변동률의 기준 인원 0명도 공란 |
| 로지스틱 회귀 | p=1/[1+exp(−(β₀+β₁×1차 미달 수+β₂×2차 미달 수))]. p≥0.5이면 통과로 분류 |
| 예측 검증 | 개인별 학습 제외 예측으로 ROC_AUC·Brier·LogLoss 평가. 소수 클래스 수에 맞춰 최대 5분할, 각 클래스 2명 미만이면 교차검증 생략. 단일 클래스는 학습 불가 |

## 6. 결과 보고 및 해석 원칙

| 분석 | 보고할 항목 | 해석할 때 구분할 내용 |
|---|---|---|
| 기술통계·변화 | 인원, 분모, 결측, 평균·표준편차, 미달률·변동률 | 인원 변화율과 미달률의 %p 차이는 다름. 누적막대에서 종목 간 장병 중복 가능 |
| ANOVA | 적용 방법, Levene p값, 적용 p값, 참고 η², 그룹별 평균 | 전체 유의성이 모든 쌍의 유의성을 의미하지 않음. 사후검정의 평균차·95% 신뢰구간·보정 p값을 함께 보고 |
| 카이제곱 | 교차표, χ²·자유도, 원·보정 p값, V, 그룹별 미달률 | 평균 차이 검정과 다름. Pearson 잔차는 탐색 지표이며 그룹 쌍별 사후검정을 대신하지 않음 |
| 상관분석 | 종목·회차별 r·ρ·p값·표본 수 | 높은 상관은 체력 향상이나 운동처방 효과의 증거가 아님 |
| 동일종목 지속 미달 | 종목별 인원, 하나 이상 해당하는 고유 장병 수·비율, 분석 분모·제외 인원 | 종목별 인원은 서로 중복될 수 있음. 매 회차 미달 종목이 달라도 포함되는 기존 `persistent_risk`와 구분 |
| 관측 통과율 | 상위·하위그룹별 평가·통과 인원, 관측 비율 | 개인별 적용 비율에는 본인의 3차 결과도 집계에 포함될 수 있어 독립 검증된 예측확률이 아님 |
| 로지스틱 예측 | 입력 변수·정답 정의, 회귀계수·오즈비, 교차검증 성능 | 전체 적합 확률과 학습 제외 확률 구분. 같은 입력 조건이면 같은 모델확률. 미래·외부 자료 검증은 별도 |

장병 위험 기준은 혼용하지 않습니다. 위험장병식별·통과율 분석은 **2개 이상 미달**, 기존 전체 현황의 ‘취약’은 **1개 이상 미달**입니다. 분석 결과만으로 연령·BMI의 인과효과나 모든 개인의 변화를 단정하지 않습니다. 특히 상대악력과 BMI는 체중이 공통으로 관여하는 지표입니다.

### 기여도와 개인 적용 비율의 구분

하위그룹 i의 자체 통과율은 rᵢ=aᵢ/nᵢ이며, 상위그룹 통과율에 대한 기여도는 다음과 같습니다.

\[
c_i=\frac{n_i}{E}r_i=\frac{a_i}{E},\qquad
R_{\mathrm{상위}}=\sum_i c_i
\]

- 기여도(%p)=100cᵢ이며, 각 상위그룹 안에서 합산하면 상위 통과율(%)입니다.
- 개인에게 소속 하위그룹의 관측 비율을 적용할 때는 **rᵢ=aᵢ/nᵢ**를 사용합니다. 기여도 cᵢ 자체를 개인 통과확률로 사용하지 않습니다.
- nᵢ>0이고 E>0일 때 기여도를 하위 인원 비중으로 다시 나누면 rᵢ로 돌아옵니다. 따라서 기여도 방식이 별도의 개인 예측모형을 만드는 것은 아닙니다.
- 3차 판정불가 인원은 평가 분모에서 제외합니다. 통과자 0명·평가자 양수이면 비율 0%, 하위 평가자 0명이면 자체율 공란입니다. 상위 평가자 양수이면 빈 하위그룹의 기여도는 0입니다.
