### 높음 — 배경 이미지가 없을 때 `app_ex.py`가 중단될 수 있음

- 근거: [`dashboard/app_ex.py`](../../../dashboard/app_ex.py)에서 `bg_img` 값이 없으면 대체 값을 사용하지만, 후속 렌더링 분기에서 `bg_css`를 조건 없이 참조합니다. 관련 코드는 대략 65~76행입니다.
- 원인 정황: [`dashboard/img/img2base64.py`](../../../dashboard/img/img2base64.py)의 변환 경로는 `bg_1` 키를 기록합니다. `bg_img`가 없는 입력 JSON에서는 `bg_css`가 대입되지 않을 수 있습니다.
- 영향: 앱 실행 시 `NameError`로 페이지 초기화가 중단될 수 있습니다. 다른 앱 진입점인 [`dashboard/app_ex_01.py`](../../../dashboard/app_ex_01.py)는 CSS 생성을 조건부로 처리하므로 동작이 일치하지 않습니다.
- 권고: 이미지가 없을 때 기본 CSS를 만들거나 `bg_css` 사용을 동일한 조건 안으로 이동하고, 두 대시보드에서 빈 이미지 입력을 각각 검증합니다.

### 중간 — CSV 로드 실패가 예시 데이터로 대체되지만 사용자 경고가 누락될 수 있음

- 근거: [`dashboard/py/loader.py`](../../../dashboard/py/loader.py)의 CSV 로더는 오류 파일을 모듈의 `_missing_files`에 기록하고 샘플 데이터를 반환합니다. 두 대시보드 앱([`app_ex.py`](../../../dashboard/app_ex.py), [`app_ex_01.py`](../../../dashboard/app_ex_01.py))은 별도의 빈 목록을 만들어 이를 표시 여부 판단에 사용합니다.
- 영향: 실제 CSV가 없거나 로드 검증에 실패해 샘플 데이터가 표시되어도 경고가 표시되지 않을 수 있습니다. 사용자가 실데이터와 예시 데이터를 혼동할 위험이 있습니다.
- 권고: 로더가 반환하는 성공 여부와 실패 파일 목록을 앱에 명시적으로 전달하고, 실패 시 샘플 데이터임을 눈에 띄게 표시합니다.

### 중간 — CSV 정의서 변환에서 결측 그룹 키를 가진 행이 조용히 빠질 수 있음

- 근거: [`data/test_py_folder/csv_data_format.py`](../csv_data_format.py)의 그룹 집계에서 `groupby(groupby_cols, ...)`가 pandas 기본 `dropna=True` 동작을 사용합니다.
- 영향: 그룹 기준 컬럼에 결측이 있는 행은 결과 집계에서 제외될 수 있으며, 현재 경로에서 별도 제외 건수나 경고가 확인되지 않았습니다.
- 권고: 결측 그룹을 결과에 포함할지 정책을 정해 `dropna=False`를 적용하거나, 제외한다면 제외 행 수와 사유를 결과·로그에 남깁니다.

### 중간 — AI 컬럼 매핑 실패가 빈 목록으로 반환되어 후속 단계가 계속될 수 있음

- 근거: [`data/test_py_folder/csv_data_format.py`](../csv_data_format.py)에서 재시도 종료 후 빈 매핑 목록을 반환하고, 호출부에서 실패 결과와 정상적인 빈 결과를 구분하지 않고 다음 매핑·집계 단계로 진행합니다.
- 영향: 실패 기록이 로그에 있어도 처리 파이프라인이 완료된 것처럼 결과를 저장·표시할 수 있습니다.
- 권고: 재시도 실패를 명시적 예외 또는 성공 여부가 포함된 결과로 전달하고, 실패 상태에서는 집계·저장을 중단합니다.

- 권고: 프로젝트에서 직접 import하는 패키지를 런타임/개발 의존성으로 명시하고, 깨끗한 환경에서 설치·테스트합니다. 이번 실행 환경의 Pylance import 검사에서는 미해결 top-level 모듈은 없었으나, 이는 선언 누락 위험을 해소하지 않습니다.

## 별도 요청: 입대 후보 BMI 구간 변경

감사와 별도로 요청된 입대 후보 조건은 기존 두 구간 대신 **단일 구간 `18.5 <= BMI < 40.0`**으로 변경했습니다. 키 필터 `159 <= 키 < 204cm`와 연령 필터 `19~24세`는 유지했습니다. 변경 파일: [`enlistment_candidates.py`](../../csv_preprocessing/enlistment_candidates.py).

합성 입력으로 BMI `18.49`, `18.5`, `39.999`, `40.0`, 비숫자, 공란을 검사했습니다. 결과는 `18.5`와 `39.999`만 선택되어 하한 포함·상한 제외 동작을 확인했습니다. 실제 `KS_NFA_TOTAL_CARDIO_DEDUPED.csv` 101,213행을 실행해 [`KS_NFA_ENLISTMENT_CANDIDATES.csv`](../../csv_file/csv_data/KS_NFA_ENLISTMENT_CANDIDATES.csv)를 갱신했으며, 후보 **98,503행**을 생성했습니다. 생성된 전체 행에서 연령 `19~24`, 키 `159 <= cm < 204`, BMI `18.5 <= BMI < 40.0`을 다시 검증했습니다. 해당 파일의 구문 검사 및 Pylance 진단도 통과했습니다.
