# 장병 체력 측정 데이터 분석계획표 (심플)

작성일: 2026-10-22 / 작성자: 우주연

## 분석 목적과 대상

장병 표본의 체력 분포, 연령·BMI별 차이, 회차별 미달 변화, 운동처방 현황·관련성을 확인합니다.

- 자료: `data/processed/KS_NFA_PROCESSED.csv`와 운동처방 자료
- 대상: 국민체력100 남성 19~24세 자료에서 전처리 조건을 통과한 표본. 원본 문서 기준 3,420명, 10,260개 측정 기록이며 자료 갱신 시 재집계합니다.
- 기본 단위: 장병별 날짜순 첫 측정 1건. 변화 분석은 동일 장병의 1·2·3차 기록을 연결합니다.
- 원본의 11·12·13번 분석과 관련 상세 설명·비교 내용을 제외하고, 남은 항목에 순번을 다시 매겼습니다. 기존에 수행한 분석을 포함한 정리 문서입니다.

## 공통 분석 기준

| 구분 | 적용 기준 |
|---|---|
| 종목별 미달 | 근력 < 51.8, 근지구력 < 42, 심폐지구력 < 42, 유연성 < 6.1. 기준과 같으면 충족, 결측은 판정불가 |
| BMI 그룹 | 첫 측정 BMI의 삼분위로 낮음·중간·높음 구분. 의학적 비만 분류와 다름 |
| 위험·취약 | 위험장병은 2개 이상 미달, 기존 전체 현황의 취약은 1개 이상 미달 |
| 유의수준 | 기본 α=0.05. ANOVA는 유의 시 Tukey 또는 Games–Howell 사후검정. 카이제곱 및 처방 관련성은 각 분석의 Holm 보정 기준 적용 |
| 처방 현황 단위 | 처방 기록이 있는 고유 측정번호 기준. 한 측정에 여러 운동이 포함될 수 있어 운동별 포함률 합계는 100%를 넘을 수 있음 |
| 처방 관련성 대상 | 첫 측정 당시 19~24세 중 해당 측정에 처방 기록이 있는 장병. 종목 결측은 해당 검정에서 제외 |

## 준비 및 결과 정리

- `check_분석데이터.py`로 장병별 기록 수·중복·결측을 확인합니다.
- `장병별_회차별미달정보생성.py`로 최신 회차별 미달자료를 생성한 뒤 후속 분석을 수행합니다.
- 분석별 대상 인원·제외 인원·분모를 기록하고, 표·그래프·CSV로 결과를 정리합니다.
- 연령·BMI 및 운동처방의 관련성을 인과효과나 운동 수행에 따른 개선 효과로 단정하지 않습니다. 표본의 선정 조건과 대표성 한계를 함께 설명합니다.
