# 부상 현황 — 6번 화면

## 실행

```powershell
python -m data.scripts.analysis.injury_overview
python -m streamlit run dashboard/장병체력_부상현황.py
```

`python -m data.scripts.main analysis`에도 부상 현황 분석이 등록되어 있습니다.

## 입력

기존 KS_NFA_PROCESSED.csv, SOLDIER_PERSONNEL.csv, SOLDIER_INJURY.csv를 읽기만 합니다.
신상과 부상은 합성 자료입니다. 원본 부상에는 발생일·회복 상태·운동 제한이 없습니다.

## 산출물

위치: `data/processed/analysis/injury_overview/`

| 파일 | 한 행의 기준 | 주요 컬럼 |
|---|---|---|
| personal_injury_summary.csv | 장병 | SOLDIER_ID, 최신 MESURE_ID·ROUND, 종목별 GRADE, INJURY_COUNT, HAS_INJURY |
| grade_injury_summary.csv | 종목·등급 | 전체인원·부상인원·부상건수·부상자비율 |
| injury_summary.csv | 전체 집계 | 전체장병수·부상인원·부상건수·부상자비율·반복부상인원·측정기록없음 |
| metadata.json | 분석 실행 | 생성일과 집계·등급·기간·합성·중복 처리 기준 |

## 기준

- 전체 장병 명단을 분모로 합니다. 부상자 비율은 기록 1건 이상인 장병 수/전체 장병 수입니다.
- 같은 장병의 여러 기록은 부상인원 1명, 부상건수 여러 건입니다.
- 체력등급은 개인별 최신 측정의 종목별 등급이며 종합 인증등급이 아닙니다.
- 측정 당시 남성 19~24세 기준 밖·누락·미측정은 판정 불가 집단입니다. 인원이 없는 등급의 비율은 빈칸입니다.
- 발생일이 없어 기간별 발생률이나 측정 당시 부상 여부를 계산하지 않습니다.
- 부상은 BMI·심폐 그룹에 따라 합성된 결과입니다. 등급별 부상 차이를 실제 위험·인과성의 증거로 해석하지 않습니다.
- 그래프의 부위·심각도 분포는 건수, 등급 비교는 장병 인원 비율입니다.
- 소속은 개인 식별 정보로만 표시하고 소속별 비교는 하지 않습니다.

## 화면

전체 부상 분포 / 체력등급별 비교 / 개인별 부상 이력의 세 탭을 제공합니다.
이름·식별자·부상 기록 수로 장병을 찾고 상세 기록과 CSV를 확인할 수 있습니다.
원본 파일이 없으면 자료 없음 안내를, 파일이 있지만 해당 장병 기록이 없으면 보유 기록 없음 안내를 표시합니다.
