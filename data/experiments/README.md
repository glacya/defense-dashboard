# data/experiments

전처리된 체력 측정 데이터로 해 본 **데이터 분석 실험 스크립트**를 모아 둔 폴더입니다. 모두 **실험용이고 최종 코드가 아닙니다.** 파이프라인(`data/scripts/main.py`)에는 들어 있지 않고, 필요할 때 하나씩 직접 실행합니다. 대부분 Streamlit 화면으로 결과를 보여 주고, 일부는 결과 CSV·HTML을 `results/`에 저장합니다.

실험용이므로 [모듈 작성 요령](../../docs/모듈-작성-요령.md) 등 팀 코드 규칙을 엄격히 지키지 않아도 됩니다(예: `sys.path` 조작, 스크립트끼리의 import, 최상위 실행 코드). 다만 분석 결과를 대시보드나 파이프라인에 쓰기로 정하면, 그 코드는 `data/scripts/`로 옮기면서 규칙에 맞게 다시 작성합니다.

```powershell
python -m streamlit run data/experiments/<파일명>.py   # 화면이 있는 스크립트
python data/experiments/<파일명>.py                    # 결과 파일만 만드는 스크립트
```

> **주의**
> - 최종 측정 데이터(`data/processed/KS_NFA_PROCESSED.csv`)에서 사람 식별자가 `M_CODE`(회원식별번호)에서 군번(`SOLDIER_ID`)으로 바뀌었습니다(2026-10-23). 모든 스크립트를 `SOLDIER_ID`로 고치고 옛 파일 이름으로 남아 있던 import도 바로잡았으며, 2026-10-23에 지금 데이터(2022-05분 포함, 장병 3,582명)로 다시 실행해 `results/`를 갱신했습니다. `results/검증결과.json`과 `results/round_correlations/%EC%9E%A5...html`은 지금 만드는 스크립트가 없는 예전 결과입니다.
>
> 결과를 다시 만들 때는 서로의 결과를 읽으므로 이 순서로 실행합니다: `장병별_회차별미달정보생성` → `종목별체력미달자_*` 3개(`--export`) → `3차통과율_체력상태조합별` → `3차통과율_하위그룹_체력상태조합별`(v1) → `3차통과율_하위그룹_체력상태조합별2` → `3차통과율_로지스틱회귀예측` → `3차통과율_장병별방법비교` → `3차통과율_저장결과비교` → `운동_체력미달정보생성` → `체력측정회차별상관분석` → `동일종목_지속미달분석`. 나머지 Streamlit 화면은 이 결과가 있으면 순서와 관계없이 실행됩니다.
> - 서로를 import하는 스크립트가 많아서, 파일 이름을 바꾸면 이를 import하는 스크립트도 함께 고쳐야 합니다. 이미 docstring의 실행 예시나 import 이름이 옛 파일 이름(예: `연령별분석`, `체력상태조합별_3차통과율`)으로 남아 있는 곳이 있습니다.

## 스크립트

### 3차 통과율 예측

| 파일 | 내용 |
|---|---|
| `3차통과율_체력상태조합별.py` | 첫 3회 측정에서 1·2차 충족/미달(미달 종목 0~1개/2개 이상) 조합별로 실제 3차 통과율을 집계합니다. |
| `3차통과율_하위그룹_체력상태조합별.py` | 위의 00/01/10/11 그룹을 1·2차 미달 종목 수(0~4개)로 세분화해 통과율을 구하고, 장병마다 소속 세부그룹의 통과율을 붙입니다. |
| `3차통과율_하위그룹_체력상태조합별2.py` | 하위그룹의 인원 가중 기여도를 더해 상위그룹의 3차 통과율을 계산합니다. |
| `3차통과율_로지스틱회귀예측.py` | 1·2차 미달 종목 수로 로지스틱 회귀를 학습해 개인별 3차 통과 확률을 예측합니다(`--first`, `--second`로 개인 예측). |
| `3차통과율_장병별방법비교.py` | 하위그룹 통과율 방식과 로지스틱 회귀 방식의 장병별 예측과 교차검증 성능을 비교합니다. |
| `3차통과율_저장결과비교.py` | 저장된 장병별 그룹 통과율과 로지스틱 예측 결과 파일을 비교합니다. |
