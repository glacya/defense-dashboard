# 개선안 리스트

작성일: 2026-10-23

## 1. 작성 기준

첨부 `S4개선안도출5성과유지관리.pdf`의 인쇄 슬라이드 33~35쪽에 따라 **분석결과에서 아이디어 도출 → 4M으로 정리 → 유사 내용 통합·중복 제거 → 개선안 리스트 작성** 순서로 정리했다. 이후 [선정 매트릭스](선정매트릭스.md)에서 효과성과 실행 가능성을 평가한다.

분석 근거와 포함 여부는 [분석결과_개선](분석결과_개선.md), 실제 수치는 [심플 분석결과](../심플_분석결과.md)를 따른다. 아래 번호는 두 문서와 같은 **15개 분석결과 번호**다. PDF의 사례 수치나 개선 효과를 본 프로젝트의 실적으로 사용하지 않았다.

대상은 첫 측정 당시 19~24세인 표본 3,420명이다. BMI 구간은 낮음 <18.5, 보통 18.5 이상~25 미만, 높음 ≥25이며 보통에는 정상·비만전단계가 포함된다. 이 문서의 개선 내용은 실행 제안이며 실제 효과가 확인된 조치는 아니다.

4M은 사람·시설·자료·방법의 네 관점에서 실행 아이디어를 생각하는 틀이다. 시설 부족이나 지도 방식이 미달의 원인으로 입증된 것은 아니므로 실제 여건을 먼저 확인한다.

조회 화면은 현재 기능을 확인해 활용·보완하며, 참여·상담·관리 기록은 실행 과정에서 작성한다. 표의 ‘기존 기능 활용’은 현재 개별 분석 화면에서 가능한 조회를, ‘기능 추가·화면 연결’은 앞으로 구현할 내용을 뜻한다. 담당 배정과 관리 기록의 대시보드 입력·저장 기능은 추가 구현이 필요하다.

**A·C·D·E는 ‘누구를 먼저 확인하고 관리할지’, B는 ‘그 장병에게 제공하는 운동 지도를 어떻게 보완할지’에 초점을 둔다.** 실제 운동 내용은 지도 담당자가 개인 상태와 인력·시간·시설을 확인해 정한다. B의 적용 효과는 다음 측정에서 확인하며, 현재 효과가 입증된 운동 프로그램을 제시한 것은 아니다.

## 4. 유사 내용 통합과 중복 제거

- **A:** 결과 2·4·6·13을 통합한다. 4·6은 주요 근거이고 2·13은 보조 근거다. 비슷한 근거마다 별도 개선안을 만들지 않는다.
- **B:** 결과 8의 종목별 추이를 중심으로 도출한다. 결과 12의 전체 평균 비교는 참고자료이며 별도 개선안은 아니다.
- **C·D·E:** 여러 종목 미달, 미달 수 증가, 동일 종목 반복 미달이라는 서로 다른 관리 사유를 유지한다.
- **통합 관리:** A·C·D·E의 명단을 장병 식별자로 합치고 선정 사유를 각각 표시한다. 같은 장병이 여러 조건에 해당할 수 있으므로 대상 인원을 합산하지 않는다. B의 지도 계획은 이 명단과 연결한다.

체력 상태는 실제 측정값과 미달 종목으로 확인한다. BMI만으로 개인 상태나 지도 방법을 결정하지 않는다. ‘미달 종목 수 동일’은 종목이나 측정값까지 같다는 뜻이 아니다.

## 5. 주요 리스트에 넣지 않은 내용

| 구분 | 분석결과 번호 | 처리 이유·활용 방법 |
|---|---|---|
| 기초·참고자료 | 1·3·5·7·12·14 및 추가 탐색 | 별도 실행 대상을 정할 근거가 약하거나 현황·탐색 자료이므로 별도 주요 개선안을 만들지 않음. 12번은 B의 참고자료 |
| BMI 파생변수 검증 후보 G | 15 | 곡선 경향만으로 예측 성능 개선을 확인할 수 없음. 예측모형을 제출할 경우에만 검증할 후보로 관리 |
| 자료 유지관리 | 14와 공통 분석 기준 참고 | 현재 오류가 발견된 것은 아니므로 주요 리스트와 선정 평가에서 제외하고 공통 유지관리로 수행 |

자료 유지관리 시에는 새 자료의 누락·중복·회차 연결·판정 기준을 확인한다. 기존 자료와 히스토그램·사분위수·박스플롯을 비교해 확인이 필요한 값을 찾고 원본과 대조한다. 분포가 다르거나 극단적인 값이라는 이유만으로 삭제하지 않는다. 결측 0명은 입력값이 모두 정확하다는 뜻은 아니다.
