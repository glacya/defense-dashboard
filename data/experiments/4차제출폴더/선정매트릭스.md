# 개선안 선정 매트릭스

작성일: 2026-10-23

## 1. 선정 기준과 절차

첨부 `S4개선안도출5성과유지관리.pdf` 인쇄 슬라이드 35쪽의 **효과성 × 실행 가능성** 형식을 적용했다. [분석결과_개선](분석결과_개선.md)의 포함 판단에 따라 [개선안 리스트](개선안리스트.md)의 A~E를 평가한다. 분석 번호는 [심플 분석결과](../심플_분석결과.md)의 15개 번호를 사용한다.

선정 순서는 **개선안 정리 → 리스트 작성 → 효과성·실행 가능성 평가 → 실행 방향 결정**이다. 아래 평가는 담당 인력·시간·예산을 확인하기 전의 정성평가 초안이다.

| 평가 항목 | 판단 질문 | 적용 기준 |
|---|---|---|
| 기대 효과성 | 확인된 미달·악화 대상의 관리에 얼마나 도움이 될까? | 대상 규모, 직접 관리 가능성, 관리 누락 방지와 종목별 보완에 대한 기대 기여도 |
| 실행 가능성 | 기존 자료와 환경으로 시작할 수 있을까? | 대상 확인 가능 여부, 필요한 담당 인력·시간·시설, 추가 비용과 협업 부담 |
| 보완 조건 | 실행 전에 무엇을 더 확인해야 할까? | 실제 담당 배정, 지도 시간·시설, 현장 수용성, 후속 평가 일정 |

효과성 ‘높음’은 기대 기여도가 높다는 뜻이며 체력 향상 효과가 검증됐다는 뜻은 아니다. A·C·D·E는 **명단 작성·상태 점검 착수**를 기준으로, B는 **보완 지도 시범 운영**에 필요한 조정까지 고려해 실행 가능성을 평가했다. 실제 운영 여건 확인 후 재평가한다.

## 2. 효과성 × 실행 가능성 매트릭스

| 효과성 ↑ / 실행 가능성 → | 낮음 | 높음 |
|---|---|---|
| **높음** | **장기 과제로 이관** — B. 심폐·근지구력 미달 장병의 운동 지도 보완 | **최우선 실행** — A. BMI 높은 그룹 미달자 점검 / C. 여러 종목 미달자 관리 / D. 미달 수 증가자 점검 / E. 동일 종목 지속 미달자 관리 |
| **상대적으로 낮음** | **보류 / 폐기** — 현재 해당 없음 | **빠른 실행(Quick Win)** — 현재 별도 선정 항목 없음 |

빈 칸을 채우기 위해 새로운 개선안을 임의로 추가하지 않았다. B는 운영 조정이 필요하다는 의미이며, 여건 점검과 시범 계획 준비는 먼저 시작할 수 있다.

## 3. 개선안별 평가와 선정 이유

| ID | 개선안 | 연결 결과 번호 | 기대 효과성 | 실행 가능성 | 선정 결과 | 판단 이유·실행 조건 |
|---|---|---|---|---|---|---|
| A | BMI가 높고 근력·심폐가 미달인 장병 먼저 확인 | 4·6 주요, 2·13 보조 | 높음 | 높음: 선별·점검 | 최우선 실행 | 높음 그룹의 근력·심폐 미달률 39.70%·49.84%. 기존 자료로 실제 미달자를 확인할 수 있음. BMI만으로 판단하지 않고 개인 상태 검토 |
| B | 심폐·근지구력 미달 장병의 운동 지도 보완 | 8 주요, 12 참고 | 높음 | 낮음: 운영 조정 필요 | 장기 과제로 이관 | 3차 심폐·근지구력 미달률 24.44%·24.06%. 보완 필요성은 있으나 지도 인력·시간·시설·적용 기간 확인 필요 |
| C | 2개 이상 종목 미달 장병을 한 명단으로 관리 | 9 | 높음 | 높음: 선별·점검 | 최우선 실행 | 3차 2개 이상 미달 826명으로 대상이 구체적이며 종목 수·조합을 확인해 관리표 작성 가능 |
| D | 미달 종목이 늘어난 장병 상담·재점검 | 10 | 높음 | 높음: 선별·점검 | 최우선 실행 | 1→3차 미달 수 증가 529명을 확인 가능. 실제 측정값과 측정 조건을 확인해 상담·후속 점검 연결 |
| E | 같은 종목에서 계속 미달한 장병의 지도 보완 | 11 | 높음 | 높음: 선별·점검 | 최우선 실행 | 같은 종목 세 회차 미달 1,063명(31.08%). 종목별 대상 확인과 지도 내용 점검 가능 |

A·C·D·E 사이의 세부 순위는 정하지 않았다. 통합 명단에서 선정 사유가 겹치는지, 실제 측정값이 어떤지, 담당 인력이 얼마나 가능한지 확인한 뒤 정한다. 높은 실행 가능성이 모든 대상의 추가 훈련 자원 확보를 의미하지는 않는다.

## 4. 선정 이후 실행 방향

| 구분 | 다음에 할 일 | 확인할 산출물 |
|---|---|---|
| 공통 준비 | 자료·미달 기준·회차 연결 확인 | 대상·제외 인원과 기준 확인 기록 |
| A·C·D·E 우선 착수 | 대상 명단 통합·중복 제거 → 담당·점검일 지정 → 상태 확인·후속 조치 | 선정 사유가 표시된 통합 관리표·점검 기록 |
| B 운영 준비 | 기존 지도·참여·인력·시간·시설 확인 → 시범 계획 마련 | 대상·기간·담당·시설·평가 방법을 포함한 계획 |
| 후속 성과 확인 | 동일 대상의 미달 수·종목별 미달·반복 미달 해소 확인 | 분모와 누락·탈락 인원이 포함된 후속 결과표 |

명단 작성 완료와 체력 개선 성과는 구분한다. 구체적인 담당·기간·수치 목표는 운영 여건 확인 후 정한다. 후속 결과가 나빠지거나 점검이 누락되면 자료·참여·지도·측정 조건을 확인하고 조정한다. 전후 변화만으로 운동 효과를 확정하지 않는다.

## 5. 선정 평가에서 분리한 내용

- **자료 유지관리:** 결과 14번은 현황 확인 자료다. 새 자료의 분포 비교·입력 오류 점검은 별도 공통 관리로 수행하며 주요 사분면에는 배치하지 않는다.
- **후보 G:** 결과 15번의 BMI 비선형 탐색은 예측 성능 개선의 증거가 아니다. 예측모형을 제출할 경우에만 BMI 파생변수를 검증하고 채택 여부를 판단한다.
- **그 외 미포함 분석:** 결과 1·3·5·7·12와 추가 탐색은 기초·참고자료로 활용한다. 12번은 B의 참고자료로만 연결한다.
