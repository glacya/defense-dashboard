# 장병 체력 측정 데이터 분석계획표 (심플)

작성일: 2026-10-22 / 작성자: 우주연

## 분석 목적과 대상

장병 표본의 체력 분포, 연령·BMI별 차이, 회차별 미달 변화, 운동처방 현황·관련성을 확인합니다.

- 자료: `data/processed/KS_NFA_PROCESSED.csv`와 운동처방 자료
- 대상: 국민체력100 남성 19~24세 자료에서 전처리 조건을 통과한 표본. 2026-10-26 현재 CSV 기준 장병 3,582명, 10,746개 측정 기록(1인당 3회)이며 자료 갱신 시 재집계합니다. 첫 측정 당시 19~24세 조건에 따른 추가 제외 인원은 0명입니다.
- 운동처방 관련성 분석은 첫 측정 대상 3,582명 중 해당 측정번호에 처방 기록이 연결된 3,110명을 사용하며, 연결되지 않는 472명은 제외합니다. 등록 운동 521개×체력 4요소, 총 2,084개 조합입니다. 이는 첫 측정 기준으로 3차 처방 분석의 대상 인원과 구분합니다.
- 기본 단위: 장병별 날짜순 첫 측정 1건. 변화 분석은 동일 장병의 1·2·3차 기록을 연결합니다.
- 원본의 11·12·13번 분석과 관련 상세 설명·비교 내용을 제외하고, 남은 항목에 순번을 다시 매겼습니다. 기존에 수행한 분석을 포함한 정리 문서입니다.

## 공통 분석 기준

| 구분 | 적용 기준 |
|---|---|
| 종목별 미달 | 근력 < 51.8, 근지구력 < 42, 심폐지구력 < 42, 유연성 < 6.1. 기준과 같으면 충족, 결측은 판정불가 |
| BMI 그룹 | 첫 측정 BMI로 낮음(<18.5)·보통(18.5 이상~25 미만)·높음(25 이상) 구분. 대한비만학회 기준을 통합한 분석용 분류 |
| 위험·취약 | 위험장병은 2개 이상 미달, 기존 전체 현황의 취약은 1개 이상 미달 |
| 유의수준 | 기본 α=0.05. ANOVA는 유의 시 Tukey 또는 Games–Howell 사후검정. 카이제곱 및 처방 관련성은 각 분석의 Holm 보정 기준 적용 |
| 처방 현황 단위 | 처방 기록이 있는 고유 측정번호 기준. 한 측정에 여러 운동이 포함될 수 있어 운동별 포함률 합계는 100%를 넘을 수 있음 |
| 처방 관련성 대상 | 첫 측정 당시 19~24세 중 해당 측정에 처방 기록이 있는 장병. 종목 결측은 해당 검정에서 제외 |

## 준비 및 결과 정리

- `check_분석데이터.py`로 장병별 기록 수·중복·결측을 확인합니다.
- `장병별_회차별미달정보생성.py`로 최신 회차별 미달자료를 생성한 뒤 후속 분석을 수행합니다.
- 분석별 대상 인원·제외 인원·분모를 기록하고, 표·그래프·CSV로 결과를 정리합니다.
- 연령·BMI 및 운동처방의 관련성을 인과효과나 운동 수행에 따른 개선 효과로 단정하지 않습니다. 표본의 선정 조건과 대표성 한계를 함께 설명합니다.

BMI 분류 출처: [대한비만학회 비만 진료지침 2022](https://general.kosso.or.kr/html/user/core/view/reaction/main/kosso/inc/data/guideline2022_vol8.pdf). 보통은 정상·비만전단계, 높음은 1·2·3단계 비만을 통합한 분석용 그룹입니다.

## BMI 비선형성 탐색의 해석·산출물

- 첫 측정 당시 19~24세의 장병별 첫 측정 1건을 사용합니다. BMI 자체와의 비교는 제외하고 나머지 5개 항목을 분석합니다.
- BMI 결측·0 이하 및 항목별 결측을 제외하고 실제 인원을 보고합니다. 개인 측정값을 선으로 연결하지 않습니다.
- 기본 BMI 구간 폭은 1이며, 0.5·1·2 중 선택합니다. 구간은 [시작, 끝)이며 인원이 20명 미만인 구간은 기본 평균선에서 제외하고 원자료·통계표는 유지합니다.
- LOWESS 기본 평활 비율은 0.4입니다. 구간 폭·평활 비율에 따라 형태가 달라질 수 있고, 양끝 희소 구간과 극단값을 함께 확인합니다.
- 비선형성이 관찰되면 BMI²·구간별 선형항·스플라인을 후보로 검토합니다. 곡선만으로 비선형성을 확정하거나 파생변수 사용을 자동 결정하지 않습니다.
- 예측모형에 적용할 경우 파생변수·설정은 학습자료 안에서 선택하고 교차검증으로 비교합니다. 현재 통과확률 로지스틱 모형의 입력에 BMI를 추가한 것은 아닙니다.
- 산출물: `results/BMI비선형성분석/`의 분석대상·설정 CSV, 항목별 구간통계·LOWESS CSV, 인터랙티브 HTML 그래프.
