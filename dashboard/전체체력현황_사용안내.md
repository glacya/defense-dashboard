# 전체 체력 현황 (1번 화면)

## 실행

프로젝트 루트에서 분석 후 화면을 실행합니다.

```powershell
python -m data.scripts.analysis.fitness_overview
python -m streamlit run dashboard/장병체력_전체현황.py
```

`python -m data.scripts.main analysis`로도 분석할 수 있습니다.
기존 `run_dashboard.ps1`은 기존 `app.py`를 실행하므로 위 명령을 사용합니다.

## 입력과 출력

원본 `data/processed/KS_NFA_PROCESSED.csv`와
`data/synthetic/SOLDIER_PERSONNEL.csv`는 읽기만 합니다.
분석 결과는 `data/processed/analysis/fitness_overview/`에 저장합니다.

| 파일 | 한 행의 기준 | 내용 |
|---|---|---|
| measurement_judgments.csv | MESURE_ID | SOLDIER_ID·회차·종목별 등급과 미달·판정 가능 개수·미달 개수·복수 미달·악화·지속 미달·통합 관리 여부 |
| round_summary.csv | 소속·비교기준·회차 | 명단 인원·비교 인원·측정 인원·판정 가능/불완전 인원·미달 인원/비율·중복 제거 관리 대상 인원 |
| event_summary.csv | 소속·비교기준·회차·종목 | 단위·유효 측정 인원·평균·표본 표준편차·판정 가능/불가 인원·미달 인원/비율·1/2/3등급 인원 |
| metadata.json | 분석 실행 | 입력 경로·생성일·측정 기간·집계 및 판정 기준·등급 하한 |

판정 CSV에는 원본 측정값을 반복 저장하지 않으며 MESURE_ID로 연결합니다.
식별자는 문자열, 회차·개수는 정수, 판정은 True/False, 판정 불가는 빈칸입니다.
GRADE의 0은 3등급 미만이며 종합 인증등급이 아닙니다.
결과는 재분석 시 갱신하며 사용자 입력 관리 기록은 포함하지 않습니다.

## 집계 기준

- 원본의 모든 측정을 날짜순으로 유지합니다. 같은 날짜는 입력 순서입니다.
- 측정 당시 남성 19~24세 기준으로 판정합니다. 범위 밖 연령·누락은 판정 불가입니다.
- 첫 측정 연령만으로 표본을 제한하는 기존 실험 보고서와는 기준을 구분합니다.
- 전체 장병 수는 명단 기준, 측정·비교 대상은 측정 자료 기준입니다. 측정이 전혀 없는 소속은 이 화면의 소속 필터에 나타나지 않습니다.
- 전체 미달률은 네 종목 모두 판정 가능한 장병 중 한 종목 이상 미달한 비율입니다.
- 종목별 미달률은 해당 종목 판정 가능 인원을 분모로 합니다. 분모 0은 빈칸입니다.
- 평균·표준편차는 연령 판정 가능 여부와 별개로 해당 종목의 유효한 측정값에서 계산합니다. 표준편차는 ddof=1입니다.
- 동일 장병은 원본의 전체 회차에 기록이 있는 집단이며, 판정 가능한 집단이 같다는 뜻은 아닙니다.
- 관리 대상은 BMI≥25이면서 근력 또는 심폐 미달, 해당 회차 2개 이상 미달, 1차 대비 미달 개수 증가, 동일 종목 최근 3회 모두 미달의 합집합입니다. 미래 측정을 사용하지 않습니다.
- 완전한 3회 반복 자료에서는 지속 미달이 1·2·3차 비교입니다. 첫 두 회차는 지속 미달 판정 대상이 아닙니다.
- 과거 소속 이동 자료가 없어 명단의 현재 소속으로 모든 회차를 집계합니다. 신상·소속은 합성 자료입니다.

## 화면 범위

소속·회차·비교 집단 필터, 핵심 지표, 종목별 평균과 미달률,
등급 분포, 회차별 인원 및 미달 추이, 집계표·다운로드·기준 안내를 제공합니다.
2~7번 화면과 실제 상담·후속조치 입력 기능은 포함하지 않습니다.
