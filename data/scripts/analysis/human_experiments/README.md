# human_experiments

사람이 직접 할 때와 프로그램(알고리즘·대시보드)으로 할 때를 비교하는 실험 페이지를 만드는 스크립트입니다.
각 스크립트는 템플릿 HTML에 데이터를 채워 `data/intermediate/human_experiments/`(Git 제외)에 저장합니다.
페이지에는 측정값·합성 신상이 들어 있으므로 결과 HTML은 Git에 올리지 않습니다.

미달 예측 모델과 사람의 비교 실험은 `failure_prediction/experiments/`에 있습니다.

| 파일 | 역할 |
|---|---|
| `build_weak_element_quiz.py` + `weak_element_quiz_template.html` | 실험 1: 취약 체력 요소 판별 → `weak_element_quiz.html` |
| `build_followup_entry_task.py` + `followup_entry_task_template.html` | 실험 2: 후속조치 입력 시간 → `followup_entry_task.html` |

```powershell
python data/scripts/analysis/human_experiments/build_weak_element_quiz.py [--seed 1103] [--count 100]
python data/scripts/analysis/human_experiments/build_followup_entry_task.py [--seed 1103] [--count 25]
```

## 실험 1: 취약 체력 요소 판별

- **질문**: 측정값만 보고 취약 체력 요소를 고를 때 사람은 얼마나 정확하고 얼마나 걸리는가, 판정 알고리즘과 비교하면 어떤가.
- **문항**: 최종 측정 10,746건에서 시드로 측정 100건을 무작위로 뽑는다(같은 장병의 측정이 여러 번 나와도 됨).
- **요소와 기준**: 근력·근지구력·심폐지구력·유연성은 3등급 하한 미만, BMI는 18.5 미만 또는 25 이상, 체지방률은 7 이하 또는 27 이상이면 취약이다. 대시보드 `add_deficiency_flags`와 같고, 값은 `fitness_standards`에서 가져온다.
- **진행**: 참가자는 기준표(화면 왼쪽에 고정)를 보며 측정마다 취약한 요소의 값 칸을 누르거나, 없으면 '취약 없음'을 누른다. 푸는 동안에는 진행도만 보이고 시간은 보이지 않는다.
- **알고리즘**: 같은 기준을 브라우저에서 화면과 같은 값으로 비교한다. 생성 스크립트는 이 식의 결과가 pandas로 계산한 정답과 같은지 확인한다. 그래서 알고리즘의 정답률은 100%여야 한다.
- **지표**: 정답률 = 맞힌 칸 ÷ 600칸(100건 × 6요소). 요소 6개를 모두 맞힌 측정 수와 요소별 정답률도 함께 보여 준다. 답하지 않은 측정은 모든 요소를 취약 아님으로 채점한다.
- **시간**: 사람은 시작부터 제출까지, 알고리즘은 100건 판정을 여러 번 반복한 1회 평균이다.

## 실험 2: 후속조치 입력 시간

- **질문**: 대시보드 7번 화면에서 체력 후속조치 기록 25건을 장병별로 작성하는 데 얼마나 걸리는가.
- **대상**: 다음 체력검정 미달 확률이 30% 이상인 후속조치 대상 장병에서 시드로 25명을 무작위로 뽑는다. 명단은 대시보드처럼 확률이 높은 순서다.
- **화면**: 대시보드의 '선택 장병 정보'와 같은 항목(확률, 대상자 등급, 나이, BMI, 운동유형, 최신 측정 4종목과 3등급 하한)을 보여 준다. 폼은 `FIELDS['followup_records']`와 같은 항목·기본값(상담일·다음 점검일은 오늘, 상태는 점검 대기)을 쓴다.
- **검사**: 저장할 때 `management_store.validate`와 같은 규칙으로 검사하고, 맞지 않으면 저장하지 않는다.
- **지표**: 시간만 잰다. 전체 시간(시작부터 최종 제출까지), 기록 1건당 평균, 장병별 시간의 중앙값과 가장 오래 걸린 장병을 보여 준다. 장병별 시간은 바로 앞 저장(첫 장병은 시작)부터 그 장병의 첫 저장까지다. 푸는 동안에는 진행도만 보인다.
- **저장**: 입력한 기록은 페이지 안에만 있다. DB나 파일에 저장하지 않는다.
- **범위 밖**: 대시보드의 그룹별 등록(여러 장병에게 같은 기록을 한 번에 등록)은 재지 않는다.

## 주의

- 실험 참가자가 결과를 미리 알지 않도록, 스크립트는 문항의 정답 분포를 출력하지 않는다.
- 정답은 페이지에 섞어서 싣는다. 페이지 소스를 열면 풀 수 있으므로 참가자는 소스를 보지 않는다.
